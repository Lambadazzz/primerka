# Примерка Юлки

Рабочий проект восстановлен из публичной сборки Lambadazzz/primerka. Исходники старого приложения не сохранились; src/legacy.js содержит сохранённый опубликованный движок и небольшой явный bridge, новые модули отделены. Не переписывать его целиком и не менять прежние ключи IndexedDB keyval-store/keyval: state и img:<id>. Рисование хранится отдельно paint:<context>, каталог paint:catalog, резервная копия paint:backup. Все пользовательские фото/проекты только локальны. Не включать их в публикацию.

Согласовано: две новые GLB-модели мужская/женская с руками вдоль тела, варианты руки с плечом/ноги/стороны, старые четыре модели сохраняются; редактор для подрисовки наложенной тату и разметки со стилусом Xiaomi Pad 6, фото отдельным слоем, слои/нажим/отмена/кисти, проект/PNG/снимок. Новые модели выделены вариантом 3 и отдельными контекстами сохранения. Предполагается PWA, без APK и переустановки при обновлении.

npm install; npm test; npm run build; npm run dev (5180). На этом компьютере esbuild может требовать разрешённого запуска вне песочницы. scripts/build-models.mjs воспроизводит новые модели; scripts/geometry-runtime.mjs — извлечённый геометрический runtime для сборки/тестов. Сборка dist; GitHub Pages публикует статические файлы из корня репозитория. Сначала загружать models и assets, затем index.html/sw.js/README одним коммитом. Сверять SHA256 публичных файлов после Pages. Удалять старые ассеты не нужно — ими могут пользоваться старые PWA-клиенты.

Проверять сквозной импорт/экспорт, работу при изменении модели/стороны, Ctrl+Z и ластик, обновление старого service worker и сохранность фото. Не выдавать браузерные проверки за реальные испытания Xiaomi/стилуса. Локальные тестовые проекты/PNG в Downloads не публиковать.

Управление 2.2: палец/стилус на теле рисуют, один палец с фона вращает; два пальца на теле или фоне не рисуют: короткое касание — undo, движение — pan, щипок — zoom. При втором пальце предварительный незавершённый штрих убирается с восстановлением history/redo. До отпускания всех пальцев рисование не возобновлять. Сглаживание непрерывного штриха не сбрасывать при смене поверхностного участка; на стыке соединять с предыдущей точкой. Пустой getCoalescedEvents должен обрабатываться как исходное событие.
